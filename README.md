# bootstrap-ct

Проект в якості диплопної роботи на курсі Frontend-Basic 
Питання розглянуті в роботі:
1. Огляд готової комерційної теми Premium Bootstrap 5 UI Kit soft-ui 3 https://www.creative-tim.com/product/soft-ui-design-system-pro
2. Практика створення сторінок на основі готових блоків теми, взаємодія з Bootstrap 5
3. Огляд можливостей адаптації сторінок та затрат часу на адаптив
4. Gulp для оптимізації зображень, мінімізації коду стилів під конкретні сторінки
5. Тестування в браузерах зовнішнього вигляду та тестування на помилки коду
6. Опис додаткових/не фреймворкових дій , зауваження
7. Висновки
-----

1. Premium Bootstrap 5 UI Kit soft-ui3 -
   преміальна тема від команди розробників, що розробили ряд проектів/тем з використанням сучасних технологій розробки Frontend-у,
   таких як Bootstrap(3-4-5), MaterialUI, React, Vue, Angular і інші
   Мій вибір на Bootstrap 5 UI Kit soft-ui3 базується на попередньому досвіді роботи з Bootstrap, бажанні працювати з flex-сіткою,
   яку використовує Bootstrap5 та приємному вигляді теми Soft-ui3 в купі з великим набором візуально вирішених блоків
2. Практика створення сторінок на основі готових блоків теми, взаємодія з Bootstrap 5 -
   в роботі було створено дві різні за структурою сторінки, повторюваний код яких навігація в шапці та футер, інші блоки - різні на цих сторінках.
   Перша сторінка - обкладинка веб-порталу 
   Друга сторінка - обкладинка компанії учасниці каталогу веб-порталу
   Обидві сторінки мають однаковий стиль теми і різне наповнення
   Розробники теми пропонують підключити файли бутстрапу через cdn і проінсталити тему чи підключити файли вручну, я обрала підключити файли вручну
   Моє перше враження від використання готових блоків - бракувало адаптивності, яку довелося брати в документації  bootstrap5 - все спрацювало добре
   бракувало саме тих блоків які були заплановані в плані сторінки  - bootstrap5 - все спрацювало добре
   Не підключилися іконки з коробки, хоча з вигляду все норм, не підключився datepicker, шрифт я б змінила на інший
3. Для адаптації теми під мобільні та планшети довелося внести зміни в перелік класів навігації та замінити її код на bootstrap5 для мобільного меню,
   Деякі блоки потрібно було визначити як виглядатимуть на менших девайсах та додати/прибрати відповідні класи bootstrap5 в елементах

4. Gulp для оптимізації зображень, мінімізації коду стилів під конкретні сторінки
   To be continued

5. Дописані блоки при тестуванні не були готові до мобільних - їх довелося адаптувати додатково
   При перевірці якості коду не було нарікань на полотно використаних класів в блоках, та були нарікання на контекст використання кнопки,
   і на зайві стилі і скрипти, що не використовуються - рішення Gulp (п.4)

6. Додатково на даному етапі я додала місце під логотип інлайн стилями на другій сторінці використовуючи position: relative, top, margin, padding, display:inline-block
   В даній роботі я знехтувала процесом створення репозеторію і пушів, як наслідок - проблеми з файлами і шляхами при роботі з github-браузерною версією
   На гітхаб pages чомусь не завантажилась папка з зображеннями хоча вона є і в тій гілці
   To be continued with Gulp-оптимізованою на іншій гілці.
   Все ж таки процес завантаження на github через обмін з локальним репозиторієм мені особисто не дуже подобається
   
   
8. Використання готової теми / фреймворку пришвидшує термін розробки продукту, дозволяє запустити гарний адаптивний сайт з мінімальними витратами часу,
   проте оскільки тема готова при зміні дизайн-бачення деякі зміни можуть бути болючими
